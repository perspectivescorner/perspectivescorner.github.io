Privacy policy

Last updated: November 15, 2026

This policy covers this website and "PC Analytics", the small tool PerspectivesCorner uses to publish and manage videos on its own YouTube channel.

This website

This website has no sign-up, no forms, no cookies, no analytics and no advertising. It is hosted on GitHub Pages; GitHub may keep standard server logs (such as IP addresses) for security, as described in the GitHub Privacy Statement.

PC Analytics (YouTube API Services)

PC Analytics uses YouTube API Services. It is used only by the PerspectivesCorner team, signed in to the PerspectivesCorner Google account, to upload, schedule and edit videos and to read view statistics for the PerspectivesCorner channel. It is not offered to the public.

  • It accesses only the PerspectivesCorner channel's own videos, playlists and statistics.
  • It does not collect, store or share personal information about viewers or any other YouTube users.
  • The sign-in token is kept on the team's own computer and is used only to talk to YouTube. It is never sold or shared.
  • Channel statistics are kept on the team's computer to plan future videos, and are not shared with third parties.

By using YouTube you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access granted to PC Analytics can be removed at any time at Google Account permissions.
